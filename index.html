使用方式
  1. 用 Pybricks Code 把程式下載到 Hub，並關閉 Pybricks Code 的藍牙連線（藍牙同時只能連一個裝置）。
  2. 按 Hub 的藍牙按鈕啟動程式，等待燈號閃爍藍色。
  3. 在本頁按「連接 Hub」，選擇你的 Hub。
  • 電腦／Android：使用 Chrome 或 Edge，並透過 https 開啟（GitHub Pages 已符合）。
  • iPad／iPhone：Safari 與 Chrome 都不支援 Web Bluetooth，請安裝 App Store 的 Bluefy 瀏覽器，用它開啟本頁。
  • 頁面載入後即使關閉 Wi‑Fi，藍牙資料仍會持續更新。
