使用方式
  1. 用 Pybricks Code 把程式下載到 Hub，並關閉 Pybricks Code 的藍牙連線（藍牙同時只能連一個裝置）。
  2. 按 Hub 的藍牙按鈕啟動程式，等待燈號閃爍藍色。
  3. 在本頁按「連接 Hub」，選擇你的 Hub。
  4. 需使用 Chrome、Edge 或 Android 版 Chrome，並透過 https 開啟（GitHub Pages 已符合）。iPhone／Safari 不支援 Web Bluetooth。
